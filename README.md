# ProjectCounter

This project will keep track of the stitches and rows of a crochet project.

## The Problem

I want to solve the problem of losing track of progress in a crochet project. It’s easy to forget stitch and row count.

## How It Works

- create a new project for the user
- keep track of the stitches and rows of the current project
- read input from the user for how to move forward


## Tech Stack

- **Language:** Java 
- **Libraries:** Java Scanner
- **External tools:** VS Code

## Setup

javac ProjectCounter.java
java ProjectCounter.java

## Usage

Rows completed: 0 | Stitches in this row: _
Type s to add stitch, r to add new row, q to quit
r
Rows completed: 1 | Stitches in this row: _ 
Type s to add stitch, r to add new row, q to quit
q
Done! You finished 1 row and _ stitches
